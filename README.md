# Hello Girls — Final Project

A responsive website developed as the final project for the **Hello Girls** course, an extension initiative focused on introducing girls and women to web development in an accessible and welcoming way.

The project was built using HTML and CSS, with a focus on responsive layout, visual organization, and basic front-end development practices.

## Live Demo

Access the project here:

```text
https://sthefaniadev.github.io/Hello-Girls-Projeto/
```

## Features

- Responsive layout
- Clean page structure using HTML5
- Styling with CSS3
- Compatible with different screen sizes
- Published with GitHub Pages

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
